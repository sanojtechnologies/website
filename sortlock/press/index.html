What it is

Sortlock is a ball sort puzzle with a twist: locks. Sort the colored balls into vials, crack the locks and try to match par. A solver checks every level before you see it, so every level can be won.

What's different

  • Every level is checked by a solver, so it can always be won.
  • Every level has a par. On almost every level it is the proven minimum.
  • On almost every board, the game tells you when a move has left you stuck, and how many moves back is still winnable.
  • Color locks, "1st/2nd/3rd" order locks, mystery balls and tall vials.
  • One daily puzzle, the same for everyone.
  • Every color also has its own symbol, for color-blind players. No timers, no account.
