Tilt Push

Press kit. A calm box-pushing puzzle where every push tips the floor, by a solo developer in India.

Get it on Google Play

What it is

Push a box one square and the whole floor tips a quarter turn. Every box then slides until a wall, another box or you stop it. Rest every box on a ring to finish the level.

What's different

  • The floor always tips the next way round: left, up, right, down. The top line says which way the next push sends the boxes, and an outline shows where each will stop.
  • You're part of the puzzle: a sliding box stops when it reaches you.
  • A grey stone that never slides, so you can put a wall where you need one.
  • 80 levels, each checked by computer to be finishable, each showing the fewest pushes it can be done in.
  • A new daily level every day, the same for everyone.
  • No timer and no lives, with unlimited undo. The game tells you when a level can no longer be finished.
  • Works offline, with no account. Progress stays on the device.
